## Intent

A premium case-study film for Santino Cervio's personal portfolio site, built from the
`delivery-operations-intelligence` repository. The viewer is a recruiter who will give it
under 45 seconds. In that time they must understand that this was **not** a dashboard
exercise: a 334,144-order delivery operation was reconstructed from four raw sources, the
service timeline was decomposed stage by stage, the intuitive "demand pressure causes late
orders" hypothesis was **tested and rejected on held-out dates**, and the real deterioration
was located *before the rider is ever notified*.

Tone: modern logistics-tech, high contrast, near-black canvas with a red/magenta accent,
bold geometric type, restrained motion. Reference points are Stripe/Linear product films and
Bloomberg-style data graphics — not a university slide deck.

The analytical spine is the story: **scale → the wrong answer → the real answer →
concentration → action**. The refusal to over-claim is the strongest credibility signal in
the project and is given its own beat.

## Assets

- `../../outputs/analysis/kpis.csv` — headline scale + service KPIs (Scene 2).
- `../../outputs/analysis/stage_summary.csv` — five-stage time decomposition (Scene 5).
- `../../outputs/analysis/stage_late_contrasts.csv` — late-vs-on-time gap per stage (Scene 5).
- `../../outputs/analysis/headline_contrasts.csv` — pre-event cohort, distance, pressure contrasts + bootstrap CIs (Scenes 3, 4, 6).
- `../../outputs/analysis/threshold_assessment.csv` — the rejected threshold (Scene 4).
- `../../outputs/analysis/temporal_holdout.csv` — discovery/holdout split confirming the rejection (Scene 4).
- `../../outputs/analysis/operational_segments.csv` — `hour` family, 24 rows, real hourly demand curve (Scene 3).
- `../../outputs/analysis/priorities.csv` — ranked actions, triggers, trade-offs (Scene 6).
- `../../outputs/executive_findings.json` — F01–F06 register: observation / evidence / action / limitation.
- `src/data/*.json` — frozen extracts of the above, generated by `scripts/extract-data.mjs`.

## Customizations

- Two outputs from one composition system: a 45s 16:9 case study and an 8–12s seamless
  hero loop for the site's project card.
- Count-up treatment on the Scene 2 scale KPIs and on the Scene 5 stage bars.
- Charts rebuilt as native inline SVG driven by the frozen JSON — no screenshots, no
  Plotly exports, so every mark is animatable and every number is traceable to a CSV.
- A dedicated "rejected hypothesis" beat (Scene 4) — the 95% bootstrap interval crossing
  zero, drawn as a real interval, and the threshold search failing on the holdout.
- Scene 6 labels every expected effect as an untested pilot, mirroring the repository's own
  `confidence` and `trade_off` columns.
- Reduced-motion fallback + poster frame, delivered as React components for the site.

## Notes

- **Do not invent numbers.** Every figure on screen is read from a frozen JSON extract of a
  published CSV. `scripts/verify-claims.mjs` re-checks each on-screen figure against the
  source CSV and fails the build on drift.
- **No geographic data exists.** The dataset carries `pu_distance` / `do_distance` in assumed
  metres and no latitude/longitude. Any map-like visual is explicitly schematic — a process
  network and a distance-ring diagram driven by the real distance bands — never a city map.
- **No SQL exists in the project.** The pipeline is pandas/numpy/scipy/statsmodels. SQL is
  omitted from the tech beat rather than fabricated.
- **Brand posture.** The PedidosYa logo and official typeface are not present in the
  repository and are not recreated. The film uses a brand-adjacent palette (near-black +
  red/magenta) with an original typographic lockup, and carries the repository's own
  disclaimer: not an official PedidosYa product or proof of employment
  (`docs/PUBLICATION.md`, `docs/DATA_ACCESS.md`).
- Typography must be embeddable in cloud rendering; no proprietary font is downloaded.
- Silent by design — the piece plays muted on a web page, so it carries no audio track and
  must read without narration.
